# CodeAlpha Unemployment Analysis

## Project Overview

This project analyzes unemployment data in India using Python. The analysis focuses on unemployment trends, rural vs urban unemployment, regional differences, labour participation, and the impact of COVID-19.

## Objectives

- Analyze unemployment rates in India.
- Compare rural and urban unemployment.
- Identify regions with higher average unemployment.
- Analyze labour participation rates.
- Study the impact of COVID-19 on unemployment.
- Create visual graphs to understand the data.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Datasets

The project uses two unemployment datasets containing information about unemployment rates, employment, labour participation, regions, areas, and dates.

## Analysis Performed

1. Monthly unemployment trend
2. Rural vs Urban unemployment
3. Top 10 regions with highest average unemployment
4. Labour participation rate over time
5. Unemployment before and during COVID-19

## Visualizations

The project generates five graphs:

- Monthly Unemployment Rate in India
- Average Unemployment: Rural vs Urban
- Top 10 Regions by Average Unemployment
- Labour Participation Rate Over Time
- Unemployment Before and During COVID-19

## Project Files

- `unemployment_analysis.py` - Main Python analysis program
- `Unemployment in India.csv` - Dataset 1
- `Unemployment_Rate_upto_11_2020.csv` - Dataset 2
- `01_monthly_unemployment_trend.png` - Monthly unemployment graph
- `02_rural_vs_urban.png` - Rural vs urban comparison
- `03_top_10_regions.png` - Top 10 regions
- `04_labour_participation.png` - Labour participation graph
- `05_covid_impact.png` - COVID-19 comparison
- `unemployment_analysis_report.txt` - Analysis report

## Conclusion

The analysis helps understand unemployment patterns in India and highlights changes in unemployment and labour participation during the COVID-19 period.
